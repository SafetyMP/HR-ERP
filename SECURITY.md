# Security policy

Canonical policy: **[`.github/SECURITY.md`](.github/SECURITY.md)**.

HR ERP is an **HR scaffold for testing agent governance**, not a certified payroll vendor. Report undisclosed vulnerabilities via [GitHub private advisories](https://github.com/SafetyMP/HR-ERP/security/advisories/new) — never as public issues. Use **synthetic fixtures** only ([docs/QA.md](docs/QA.md)).
